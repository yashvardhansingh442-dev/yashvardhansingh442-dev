## 📌 About Me

I'm a final-year Mechanical Engineering student at **ABES Engineering College (AKTU)**, based in **Noida, India**. My focus is the intersection of **Artificial Intelligence**, **Robotics** and **Systems Engineering**: understanding the physics and math of a system well enough to build it from scratch, in code and in CAD.

My long-term goal is to build a humanoid robotics and AGI-focused company. Right now that means three things: shipping small, tested Python projects ([MUFFIN](https://github.com/yashvardhansingh442-dev/MUFFIN), [ALGEBRA-](https://github.com/yashvardhansingh442-dev/ALGEBRA-)), building the math foundation behind them, and practicing competitive programming.

I'm currently open to **remote internships** in AI, robotics, Python and systems work, as well as 3D visualization and animation projects.

## 🚀 Featured Builds

| Build | What it is |
| --- | --- |
| 🧁 **[MUFFIN](https://github.com/yashvardhansingh442-dev/MUFFIN)** | A small Python library that sits between an AI agent and the real world: the agent can only *ask* to act, and MUFFIN checks the rules, allows or blocks each request, and keeps a record.
